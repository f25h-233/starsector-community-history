## 三条主线

**1. 平台迁移**
贴吧（2012–2015 核心期）→ 论坛建站（2018）→ 双轨并行（贴吧管游戏内容，论坛与群管社区事件）→ 贴吧作为"新玩家入口"复兴（2022–2026）。

> 2025 年贴吧帖量 **3048 条，为十五年最高**，比 2015 年军备竞赛巅峰（2099）还高出约 45%。"贴吧让位论坛"只是 2016–2021 的中期现象。

**2. 平衡文化的生与灭**
军备竞赛（"加 0"、999 点数武器）→ 贴吧铁律（2015，"修改"成为禁语）→ 论坛制度化（2018，控制台禁令 + 创作者保护）→ 群内高压管理 → 2022 年争议爆发 → 规则逐步松绑 → **2026 年 MOD 审核规定明确"强度与平衡性不做强制要求"**。

**3. 人的聚散**
社区史上的几次"人不见了"，**可见记录中都没有对应的官方处理公告**；而且——**多数人后来又以某种形式出现过**。

> 这一条只陈述"查不到官方处理记录"这一缺席证据，**不等于"确实没有发生过处理"**。查不到的原因可能是没有，也可能是记录不在公开网络上——两种可能本仓库无法区分。

### 怎么参与

**无论是吧友、群友、论坛老 id，还是刚入坑的新人，都欢迎。**

> 点上方 **Issues → New issue**，有三种模板：**纠错** / **补料** / **请求删除**。
> 不想填表就直接写，**说"我不确定"也完全可以**——标注存疑比编一个完整答案有价值得多。

- **纠错**：开 Issue，写清哪章哪句、依据是什么
- **补料**：带帖号 / 链接最好；不方便就贴内容，我们负责归档与标注
- **口述**：亲历过就直接说，我们标 **[口述]**——口述本身就是史料，只是与书面记录分开标注
- **存档**：老截图、老文件、已删视频的本地留存
- **要删**：你是被提及者、不想某条叙述留着，**说明即可，不需要理由**

**四条注意事项**（与[脱敏政策](脱敏与编辑政策.md)一致）：不要贴账号/群号/联系方式；不要提供盗版路径；不要贴私人聊天记录（除非当事双方都同意）；**不怕说"我不确定"——标注存疑比编一个完整答案有价值得多。**

> **这份清单变短的过程，就是这个项目真正的进度。**

## 关于可信度

每条结论都带标注：

**[证实]** 多源或一手公告 · **[单源]** 仅一个公开来源 · **[口述]** 当事人回忆 · **[受限]** 存在但内容不可公开访问 · **存疑**

我们**刻意保留存疑**，不替读者下最后判断。史料的价值在于"可核对"，不在于"看起来完整"。

**想核对？** 见《五、史源与核对方法》——那里有**按主题归类、可直接检索的帖号索引**。
